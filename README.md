# MushkyQT's Homebrew tap

[SlyTerm](https://github.com/MushkyQT/SlyTerm), a terminal that floats over your game.

```sh
brew install --cask mushkyqt/tap/slyterm
```

SlyTerm updates itself, so `brew upgrade` leaves it alone. `brew uninstall --cask slyterm` removes
the app; `brew uninstall --zap --cask slyterm` also removes its settings, caches and log.

The cask is updated by SlyTerm's Release workflow each time a version is published.
